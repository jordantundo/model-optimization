# Model Optimization: Hyperparameter Tuning

This repository demonstrates **GridSearchCV** and **RandomizedSearchCV** for optimizing ML models using `scikit-learn`.

## 📌 Projects
1. **GridSearchCV**
   - KNN Classifier (`gridsearch_knn.py`)
   - SVM Classifier (`gridsearch_svm.ipynb`)
2. **RandomizedSearchCV**
   - Random Forest (`randomizedsearch_rf.py`)
   - XGBoost (`randomizedsearch_xgboost.ipynb`)
